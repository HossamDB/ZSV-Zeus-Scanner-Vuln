# Code of Conduct

## Our pledge

We want ZSV's community -- issues, pull requests, discussions -- to be
welcoming and harassment-free for everyone, regardless of experience level,
background, or identity.

## Expected behavior

- Be respectful and constructive, especially in code review.
- Assume good faith; disagree with ideas, not people.
- Keep discussion focused on the project.

## Unacceptable behavior

- Harassment, insults, or personal attacks.
- Publishing others' private information without consent.
- Using this project's issue tracker to request or share help with
  unauthorized scanning/attacks against real systems. Questions about using
  ZSV against systems you don't have permission to test will be closed.

## Enforcement

Maintainers may remove comments, close issues/PRs, or block contributors
who violate this Code of Conduct. To report a concern, contact the
maintainers via the repository's contact information rather than posting
publicly.

This Code of Conduct is adapted from the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/), kept short
and specific to this project.
